# Shared harness history

This directory stores small receipts for distributed harness-learning
proposals. Git stores the actual source history; receipts make lineage, scope,
evidence, and benchmark decisions easy to inspect without committing duplicate
engine trees.

Each proposal uses `harness_history/<uuid>/proposal.edn` and follows
[`docs/PROPOSALS.md`](../docs/PROPOSALS.md). Full immutable local engine trees
remain under ignored `.forge/versions/vNNNN/`.
