# Problem packs

This repository includes the seven Clay Millennium Prize Problems:

| Problem | ID | Status |
|---|---|---|
| Birch and Swinnerton–Dyer Conjecture | `birch-swinnerton-dyer` | Open |
| Hodge Conjecture | `hodge-conjecture` | Open |
| Navier–Stokes Existence and Smoothness | `navier-stokes` | Open |
| P versus NP | `p-vs-np` | Open |
| Poincaré Conjecture | `poincare-conjecture` | Solved/reference |
| Riemann Hypothesis | `riemann-hypothesis` | Open |
| Yang–Mills Existence and Mass Gap | `yang-mills-mass-gap` | Open |

Each pack is isolated. Read its `target.md`, `problem.edn`, and `AGENTS.md`
before creating a goal. Statuses and summaries follow the Clay Mathematics
Institute's public problem pages as checked on 2026-07-23.
