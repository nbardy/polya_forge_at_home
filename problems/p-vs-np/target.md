# Target: P versus NP

- **Problem ID:** `p-vs-np`
- **Status:** open
- **Official source:** https://www.claymath.org/millennium/p-vs-np/
- **Official description author:** Stephen Cook

## Target map

The official problem asks whether the deterministic polynomial-time class `P`
equals the nondeterministic polynomial-time class `NP`, using the exact machine
and encoding conventions of the official description.

A terminal result must prove `P = NP` or `P != NP` under the official
definitions. Faster algorithms for finite instances, exponential lower bounds
for restricted circuit classes, oracle separations, heuristics, or empirical
hardness do not alone settle the endpoint.

## Campaign boundary

Every campaign must freeze its computational model, uniformity, encoding,
resource measure, reduction notion, and quantifiers. Lower-bound programs must
state which known relativization, natural-proof, or algebrization-style
barriers are relevant rather than citing them vaguely.
