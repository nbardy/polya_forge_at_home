# Goal: POINCARE-SOURCE-AUDIT-EXAMPLE

- **Status:** example; inactive until explicitly launched
- **Problem:** poincare-conjecture
- **Exact objective:** produce a bounded dependency map for one named lemma in
  a maintainer-supplied primary source
- **Main claim or deliverable:** a source-faithful statement, dependency list,
  and one deliberately planted-fault audit fixture
- **Official endpoint edge:** benchmark only; the Poincaré conjecture is solved
- **First open line:** select and pin the primary-source lemma and page/hash
- **Inputs:** the selected primary source and this solved-reference target pack
- **Exclusions:** novelty claims, prize claims, and reconstruction from memory
- **Completion criteria:** exact source locator, faithful statement, dependency
  map, planted-fault result, and independent verifier disposition
- **Kill criteria:** source cannot be lawfully obtained or the selected statement
  cannot be pinned exactly
- **Maximum briefs:** 1
- **Maximum active workers:** 2
- **Maximum model invocations:** 5
- **Maximum wall time:** 60 minutes
- **Verification budget:** one proof-withheld or source-first independent audit
- **Required outputs:** source map, failure record, verifier result, and Pólya
  receipt with no prize-progress claim
