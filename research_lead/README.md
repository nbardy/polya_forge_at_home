# Research lead

The research lead is a fresh maintainer agent that reviews proposed research
and harness learners. It is not a builder or mathematical admission authority.

Start a new Codex task in the repository and instruct it to follow
[`PROMPT.md`](PROMPT.md). Give it merge authority only when you intend it to
perform GitHub-side review or merge actions.

The lead keeps three boundaries intact:

- mathematical learning stays inside the matching problem pack;
- engine-wide memory contains process lessons only; and
- research and executable harness changes use separate pull requests.
